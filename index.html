TTE Skill目标试验模拟科研工具

在 Codex 中把临床问题写成目标试验方案，核查数据能否支持研究，再用可运行的 R 模板完成效应估计、诊断和报告。

查看使用说明 联系咨询

从选题到结果报告

适合已有临床研究问题、准备使用观察性数据进行策略比较的研究者和课题组。也可用于审阅已有方案或复核分析结果。

选题与查新

梳理已有研究和证据缺口，形成可检索、可比较的临床问题。

方案与估计目标

明确入组资格、治疗策略、共同起点、随访、结局和待估计的效应。

数据可行性核查

依据数据字典和病例时间线核实治疗时序、关键混杂因素和结局覆盖。

统计分析模板

按课题选择倾向评分加权、AIPW、TMLE、CCW、序贯试验、g-formula 或 LTMLE 的参考实现。

诊断与可视化

按方法查看协变量平衡、权重分布、有效样本量和风险曲线，导出可复核的表图。

结果与报告

将目标试验、数据定义、分析代码和结果对应起来，按 TARGET 报告要点说明假设和局限。

使用前了解

正式分析需要可访问的数据、数据字典和适合研究问题的记录。研究者据此确定数据来源、取数规则与最终方案。

Skill 可提供的资源

  • Codex Skill 工作流与方法说明
  • 目标试验方案、数据映射和分析计划模板
  • R 分析和绘图脚本、配套配置及合成数据演示

运行环境与数据条件

  • 准备 Codex 和所选分析需要的 R 依赖。
  • 真实数据访问与字段映射由研究者结合所在项目完成。
  • 研究结果取决于数据质量、设计和识别假设。统计显著性和发表结果由研究证据决定。
